# Подключение Яндекс Метрики: что сделать руками

Пять шагов, минут десять. Всё делается в вашем аккаунте — ни счётчик, ни токен
нельзя создать за вас, это действия от вашего имени.

## 1. Счётчик

https://metrika.yandex.ru → «Добавить счётчик».

- Имя: любое, например `TrackSub`.
- Сайт: адрес вашего сервиса или лендинга. Для офлайн-конверсий трафик на сайт не нужен,
  поле просто должно быть заполнено.
- Принять условия, сохранить.

Запомнить **номер счётчика** — 8 цифр в заголовке страницы. Это не секрет.

## 2. Цель

Счётчик → «Настройка» → «Цели» → «Добавить цель».

- Тип: **JavaScript-событие**.
- Идентификатор: `tg_subscription`.
- Название: «Подписка на канал».

Запомнить **идентификатор цели** (число, которое присвоила Метрика) — тоже не секрет.

## 3. Приложение для доступа к API

https://oauth.yandex.ru/client/new

- Название: `TrackSub`.
- Платформа: «Веб-сервисы», Redirect URI: `https://oauth.yandex.ru/verification_code`.
- Доступы: **Яндекс Метрика → Получение статистики, чтение параметров своих счётчиков**
  и **Управление счётчиками** (`metrika:read`, `metrika:write`).

Сохранить. Скопировать **ClientID**.

## 4. Токен

Открыть в браузере, подставив свой ClientID:

```
https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
```

Подтвердить доступ. Яндекс покажет токен в адресной строке после `access_token=`.

**Токен — это пароль от рекламной аналитики. Не присылайте его в переписку, никому и никогда.**

## 5. Ввод в сервис

http://localhost:3000/app/integrations

- Провайдер: Яндекс Метрика
- Номер счётчика: из шага 1
- Идентификатор цели: `tg_subscription`
- OAuth-токен: из шага 4

Токен шифруется AES-256-GCM ключом из `SECRET_KEY` и в интерфейсе больше не показывается.

## Проверка

```bash
node tools/yandex-check.js          # доступ к счётчику, список целей, совпадает ли цель
node tools/yandex-check.js --send   # отправить накопленные конверсии по-настоящему
node tools/yandex-check.js --queue  # состояние очереди
```

Инструмент расшифровывает токен только внутри процесса и в вывод его не печатает.

## Что важно помнить про yclid

Метрика связывает офлайн-конверсию с рекламой только по `yclid`. Значит в рекламном
объявлении Директа ссылка должна быть вида:

```
https://ваш-домен/c/СЛАГ?yclid={yclid}
```

Без этого параметра подписка будет отмечена как `skipped: в клике нет yclid` — мы не станем
выдумывать идентификатор, которого не было.

## Тариф

Передача конверсий доступна на PRO. На бесплатном тарифе интеграция не сохранится —
активировать тариф может администратор в `/admin`.
