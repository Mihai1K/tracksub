# Откуда трафик — аналитика рекламы для Telegram и MAX

Реклама → переход → канал → подписка → атрибуция → аналитика → конверсия обратно в Яндекс.
Продукт продаёт не бота, а понимание, **какая реклама приводит живых подписчиков**.

**Состояние: работающий MVP.** Сквозной путь от регистрации до конверсии проходит целиком,
на реальных интеграциях не проверен — нужны токены (см. «Что нужно для боевого запуска»).

```bash
cp .env.example .env
npm start           # http://localhost:3000
npm test            # 41 тест
```

## Главное отличие от аналогов

Мы не выдаём догадку за факт.

- **Telegram** — атрибуция точная: событие вступления приносит саму пригласительную ссылку,
  поэтому каждому переходу выдаётся своя одноразовая ссылка из пула.
- **MAX** — событие подписки источника не содержит. Точно можно только через переход по ссылке бота;
  при прямом переходе источник определяется вероятностно, с уверенностью и пометкой в интерфейсе.

Это ограничение платформы, а не недоделка. Оно написано и в интерфейсе, и в документации.

## Устройство

```
Tracking (/c/:slug, click_id, UTM)
        │
Adapters: TelegramAdapter · MaxAdapter        ← единственные, кто знает про платформы
        │
Raw Event Store (никогда не удаляется)
        │
Normalizer → Domain (подписки, отписки, повторы)
        │
Attribution Engine (версионируется, пересчитывается)
        │
Analytics Core (CPS, удержание, живой CPS)
        │
Conversion Dispatcher → YandexMetrika · YandexDirect
```

Ноль внешних зависимостей: Node 22.5+, `node:sqlite`, `node:test`. Интерфейс рендерится на сервере.

## Что нужно для боевого запуска

1. `TELEGRAM_BOT_TOKEN` и бот-администратор в канале.
2. Профиль организации на dev.max.ru и `MAX_BOT_TOKEN` — платформа доступна только резидентам РФ.
3. Домен с сертификатом доверенного УЦ: MAX принимает вебхук только по HTTPS на 443.
4. OAuth-токен Яндекса и номер счётчика Метрики — вводятся в интерфейсе для каждого проекта.

Без них адаптеры работают в режиме **mock**: очередь ведётся, наружу не уходит ничего,
и это прямо помечено в интерфейсе. Mock никогда не выдаётся за настоящую отправку.
